Caption Studio

Drop in a lecture video, get an accurate caption file you can upload alongside it. Everything runs inside this browser tab — the video never leaves this computer and no account or key is needed.

1 Choose a video or audio file
Drag files here, or press to browse
MP4, MOV, M4A, MP3, WAV, WebM · drop the whole week's videos at once — they run one after another
2 Generate the first draft
The model downloads once and is then cached by the browser, so later videos start right away. English only. “Best” is a distilled model — close to top-tier accuracy at roughly twice the speed of the original its size.
Compatibility mode uses the CPU instead of the graphics card. The page reloads, so you will add your files again — the model stays cached.
3 Review and fix — this part matters
Automatic speech recognition typically gets 90–95% of words right. For a student who relies on captions, please skim every line: fix names, course terms, and numbers, and add sound cues like [laughter] or [video plays] where they carry meaning. Click any timestamp to jump the video there.
Caption position here is only a preview. In the student’s own player the captions sit at the bottom of the picture, and most players let them be moved and resized.
4 Export
Use .srt for Canvas Studio, Panopto, YouTube and VLC. Use .vtt for a web page or an HTML5 <video> tag. Upload the caption file next to the video — that way the student can turn captions on, resize them, and search the text. The .mp4 with captions built in is one file with a real caption track (not burned-in) — it plays with captions in VLC, QuickTime, and the Windows Media Player, and the student can still turn them off or restyle them.
Where to put the caption file
  • Canvas Studio: open the video → Captions tab → Upload caption file → choose the .srt.
  • Panopto: Edit → Captions → Upload or import captions.
  • YouTube: Studio → Subtitles → the video → Add → Upload file → With timing.
  • Zoom cloud recording: Recording settings → Closed captions → upload the .vtt.
  • A plain file share: keep lecture.mp4 and lecture.srt in the same folder with the same name — VLC and most players pick captions up automatically.
Requirements and troubleshooting
  • Works best in Chrome or Edge on a desktop or laptop. Safari and Firefox may fall back to a much slower mode.
  • The very first run tests your graphics card for up to 90 seconds. If the graphics driver fails the test, the page switches itself to the CPU engine and remembers that choice — a banner at the top lets you retry the fast mode after a driver update.
  • Leave the tab open and awake while it works. Closing it stops the job.
  • If the file will not decode, re-export or convert it to MP4 (H.264/AAC) and try again.
  • Your edits are saved in this browser automatically, so a reload will not lose your work on the same file.
  • Nothing is uploaded anywhere. The only network traffic is the one-time model download.
